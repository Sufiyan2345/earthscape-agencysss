REST API Documentation

External systems can push data to EarthScape via REST API. All endpoints require an X-API-Key header.
Demo API Key: earthScape-demo-api-key-2024

POST /analyst/api/ingest/realtime

Push a single real-time reading from a sensor, weather station, or satellite.

curl -X POST http://localhost:5000/analyst/api/ingest/realtime \
  -H "Content-Type: application/json" \
  -H "X-API-Key: earthScape-demo-api-key-2024" \
  -d '{
    "stream_name": "nyc-sensor-001",
    "source_type": "sensor",
    "readings": {
      "temperature": 25.3,
      "humidity": 65.2,
      "rainfall": 0.0,
      "wind_speed": 12.5,
      "pressure": 1013.2,
      "co2_level": 415.0,
      "air_quality_index": 55
    },
    "latitude": 40.7128,
    "longitude": -74.006,
    "source_location": "New York City"
  }'

POST /analyst/api/ingest/weather-live

Fetch current weather from Open-Meteo and store it in the realtime and batch climate collections.

curl -X POST http://localhost:5000/analyst/api/ingest/weather-live \
    -H "Content-Type: application/json" \
    -H "X-API-Key: earthScape-demo-api-key-2024" \
    -d '{"location":"New York"}'

POST /analyst/api/ingest/batch

Import a batch of climate records (max 50,000 per request). Records are validated before ingestion.

curl -X POST http://localhost:5000/analyst/api/ingest/batch \
  -H "Content-Type: application/json" \
  -H "X-API-Key: earthScape-demo-api-key-2024" \
  -d '{
    "dataset_name": "My Station Data",
    "category": "weather",
    "records": [
      {"date": "2026-01-01", "station_name": "Station-A", "temperature": 5.2, "humidity": 70},
      {"date": "2026-01-02", "station_name": "Station-A", "temperature": 6.1, "humidity": 68}
    ]
  }'

GET /analyst/api/ingest/status

Check the ingestion system status and statistics.

curl http://localhost:5000/analyst/api/ingest/status?api_key=earthScape-demo-api-key-2024
